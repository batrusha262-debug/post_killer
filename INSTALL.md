# Как установить Post Killer

Эта инструкция для обычной установки. Ничего программировать, ставить Flutter
или Xcode не нужно.

> **Важно:** Post Killer пока находится в ранней разработке. Кнопка **Send**
> выполняет HTTP-запросы локально на вашем компьютере и показывает status,
> response headers и body. Не используйте приложение для рабочих секретов и
> не удаляйте Postman, если он нужен вам для production-сценариев: secure
> storage, proxy, custom CA и cookie jar пока отсутствуют.

## Установка на Mac — M-чип и Intel

Один и тот же файл подходит для всех Mac: MacBook с M1/M2/M3/M4 и старых Mac
с Intel.

1. Откройте страницу [Actions проекта](https://github.com/batrusha262-debug/post_killer/actions).
2. Слева нажмите **Release packages**.
3. Откройте самый свежий запуск с зелёной галочкой ✓. Если галочки нет,
   дождитесь завершения сборки.
4. Внизу страницы, в разделе **Artifacts**, нажмите
   **post-killer-macos-dmg**. Скачается ZIP-архив.
5. В папке «Загрузки» дважды нажмите на ZIP — появится файл
   `Post-Killer-…-macos.dmg`.
6. Дважды нажмите на `.dmg`. Откроется окно Finder.
7. Перетащите **Post Killer.app** в папку **Applications / Программы**.
8. Откройте Launchpad или Spotlight (`⌘` + пробел), введите **Post Killer** и
   запустите приложение.

### Если macOS пишет, что приложение нельзя открыть

Это ожидаемо: приложение ещё не подписано Apple-сертификатом.

1. Закройте сообщение.
2. В Finder зайдите в **Applications / Программы**.
3. Зажмите `Control`, нажмите на **Post Killer.app** и выберите **Открыть**.
4. В следующем окне снова нажмите **Открыть**.

Если такой кнопки нет: откройте **System Settings / Системные настройки →
Privacy & Security / Конфиденциальность и безопасность**, прокрутите вниз и
нажмите **Open Anyway / Всё равно открыть** рядом с сообщением о Post Killer.
Это нужно сделать только один раз.

## Установка на Windows

1. Откройте [Actions проекта](https://github.com/batrusha262-debug/post_killer/actions) →
   **Release packages** → свежий запуск с зелёной галочкой.
2. В **Artifacts** скачайте **post-killer-windows-exe**.
3. В «Загрузках» распакуйте ZIP и дважды нажмите
   `Post-Killer-…-windows-setup.exe`.
4. Нажимайте **Next → Install → Finish**.
5. Запустите **Post Killer** через меню «Пуск».

Windows может показать SmartScreen, так как приложение пока без цифровой
подписи. Нажмите **More info / Подробнее**, затем **Run anyway / Выполнить в
любом случае**, только если файл скачан по ссылке выше из этого репозитория.

## Установка на Linux

Скачайте в Actions artifact **post-killer-linux-packages**, распакуйте ZIP и
выберите один вариант:

- Ubuntu/Debian: дважды нажмите на `.deb` и выберите «Install», либо в
  терминале выполните `sudo apt install ./post-killer_<version>_amd64.deb`.
- Другие дистрибутивы: сделайте файл `.AppImage` исполняемым в свойствах файла
  и дважды нажмите на него. В терминале это: `chmod +x *.AppImage` и затем
  `./Post-Killer-*.AppImage`.

## Если на странице нет файла для скачивания

Значит первая автоматическая сборка ещё не была завершена. Исходный код уже
есть в репозитории, но для простой установки нужен успешный запуск
**Release packages**. Обратитесь к владельцу проекта или дождитесь зелёной
галочки — после неё файлы появляются в разделе Artifacts.

## Что делать после запуска

Откройте вкладку запроса, выберите метод, введите URL и при необходимости
добавьте Query, Headers или JSON Body. Нажмите **Send**: во вкладке
**Response** появятся HTTP status, время, response headers и body.

Для безопасной первой проверки используйте `GET https://httpbin.org/get`.
Если увидите ошибку сети, проверьте, что интернет работает и корпоративный
proxy/VPN не блокирует соединение; настройка proxy в приложении пока не
реализована.
